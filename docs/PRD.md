# 产品需求文档（PRD）— Speaker / 雅思口语模拟对练

> 本文档依据当前代码库已实现能力整理，用于对齐产品定位、范围与优先级。

## 1. 产品概述

### 1.1 定位

面向雅思（IELTS）备考用户的 **口语模拟对练** Web 应用：提供英式考官风格提问、通义千问（DashScope）驱动的对话与评价、题库浏览、会话历史查看与后台题库维护。

### 1.2 价值主张

- **对练**：按 Part 1 / Part 2&3 结构模拟考试流程，支持「题库话题」与「自定义话题」两种来源。
- **反馈**：单轮简短评价与整场结束后的结构化评分报告（发音、语法、连贯、流利、观点等维度）。
- **语音**：浏览器 TTS（可选）+ 浏览器语音识别或录音上传后经阿里云 ASR 转写。
- **题库**：按季节（season label）与 Part 聚合展示题目；管理端支持 Markdown 导入与逐题编辑、软删除。

### 1.3 目标用户

- 主要：备考雅思口语、需要 **反复练习与即时反馈** 的学习者。
- 次要：内容运营/教师：通过 **管理端** 维护当季题库。

## 2. 功能范围（已实现）

### 2.1 单用户访问模式

| 功能 | 说明 |
|------|------|
| 免登录访问 | 对练、历史、会话详情等普通功能无需账号或 Token。 |
| 数据归属 | 沿用数据库中最早创建的账号；空库自动创建默认账号。 |
| 管理端 | 题库管理仍使用独立 `X-Admin-Key`。 |

### 2.2 口语对练（核心）

| 功能 | 说明 |
|------|------|
| 开始会话 | 选择 Part、话题来源（题库 BANK / 自定义 CUSTOM）；题库模式可选季节、是否允许 AI 扩展提问。 |
| 多轮对话 | 用户文本或语音回答后，模型返回考官下一句、简要评价等；支持题库顺序下多题、多话题切换。 |
| 会话状态 | 服务端持久化会话与轮次（含题库进度 JSON），支持「下一话题」等流程。 |
| 结束与报告 | 完成会话后生成结构化评分与文字反馈；历史记录可查看。 |

### 2.3 语音能力

| 功能 | 说明 |
|------|------|
| ASR | 录音上传 → 后端调用 DashScope 语音识别接口。 |
| TTS | 后端按文本返回合成音频（供前端播放）。 |
| 浏览器能力 | 可选浏览器 TTS / Web Speech 识别（受浏览器与权限限制）。 |

### 2.4 当季题库（用户侧）

| 功能 | 说明 |
|------|------|
| 季节列表 | 展示未删除题目中的季节标签，并排序（默认季优先）。 |
| 按 Part 浏览 | Part 1 或 Part 2&3 聚合为 topic 分组展示题目与参考答案/关键词。 |
| 搜索 | 按 topic 模糊搜索（公开接口）。 |

### 2.5 历史与详情

| 功能 | 说明 |
|------|------|
| 会话列表 | 分页查询当前用户的练习会话。 |
| 删除记录 | 软删除当前用户一条会话。 |
| 会话详情 | 查看会话元信息、对话轮次、评分报告（若存在）。 |

### 2.6 管理端（题库）

| 功能 | 说明 |
|------|------|
| 访问控制 | 请求头 `X-Admin-Key` 与配置 `app.admin.api-key` 一致（非空时生效）。 |
| Markdown 导入 | Part1 / Part2&3 两段 Markdown 解析入库；可替换某季节全部题目。 |
| 预览 | 导入前预览解析统计与样例。 |
| 题目管理 | 按季节与 segment（part1 / part23）列表；编辑、单题软删除、整季软删除。 |

### 2.7 运维与健康

| 功能 | 说明 |
|------|------|
| 健康检查 | `GET /api/health` 供探活。 |
| 题库初始化 | 可选从资源文件向空库导入种子数据（若实现于启动逻辑）。 |

## 3. 非功能需求（已实现）

| 类别 | 说明 |
|------|------|
| 安全 | 普通业务接口免登录；管理端独立 API Key；CORS 可配置。公网部署需额外限制访问来源。 |
| 限流 | 按 IP 对通用 `/api` 与重 AI 的 `/api/practice` POST 分桶限流。 |
| 缓存 | 题库「季节列表」「按季+Part 聚合题目」可配置 JVM 内存或 Redis；后台写操作会失效缓存。 |
| 可观测 | 请求 ID、接口切面日志、全局异常处理、可选文件日志。 |

## 4. 产品现状与边界

### 4.1 当前形态

- **前端**：Vue 3 + Vue Router + Pinia + Vite，开发环境通过代理访问后端 `/api`。
- **后端**：Spring Boot 3 + MyBatis-Plus + MySQL；可选 Redis 缓存；阿里云 DashScope（对话 / ASR / TTS）。
- **微信小程序相关配置**：预留 `app.wechat` 等配置项，**当前 Web 端未完整实现小程序闭环**（以代码为准）。

### 4.2 已知限制（如实描述）

- 口语体验依赖 **浏览器与网络**；语音识别/麦克风权限因环境而异。
- 管理端依赖 **API Key** 与 HTTPS 部署习惯，生产环境需自行加固密钥与访问控制。
- Redis 与后端 **同机或可达** 时才建议开启 `app.cache.use-redis=true`；本地开发常用内存缓存。

### 4.3 后续可演进方向（非承诺）

- 微信小程序完整 API 对接。
- 题库版本、审核流、多人协作。
- 更丰富的统计看板与导出能力。
